# Farmily 🌱💰

Farmily is a gamified financial literacy application designed for children aged 6–12. It transforms everyday money management into an interactive virtual farming experience, helping children develop healthy financial habits through play.

As children save money, manage their allowance, and achieve financial goals, their virtual farm grows and evolves. Parents can monitor progress, set spending limits, and encourage responsible financial behavior in a fun and engaging way.

## Project Overview

Farmily was created to address the lack of practical financial education for children and to help parents teach money management in an enjoyable and sustainable way.

The application allows children to:

- Learn budgeting and money management.
- Practice saving toward financial goals.
- Make responsible spending decisions.
- Earn in-game rewards based on good financial habits.
- Develop financial literacy through real-life scenarios.

Parents can:

- Set allowance amounts.
- Define spending limits for different categories.
- Track their child's financial progress.
- Verify completed saving goals.
- Encourage positive financial behavior.

## How It Works

1. Parents create and manage their child's profile.
2. Allowance and spending limits are assigned.
3. Children save money and manage their spending.
4. Financial achievements unlock in-game rewards.
5. The virtual farm grows based on the child's progress.
6. Parents can approve completed saving goals and monitor development.

## Data & Privacy

Farmily is designed with children's privacy in mind.

- No sensitive personal data is collected.
- Data is generated automatically during gameplay.
- The application relies on user interactions and in-game financial decisions.
- No external datasets are required.
- Children's information is not shared with third parties.
